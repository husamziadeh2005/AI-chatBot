🤖 AI Chatbot

A simple and responsive AI chatbot built with HTML, CSS, and JavaScript, integrated with the Google Gemini API to generate AI-powered responses.

✨ Features

* 💬 Real-time AI conversations
* 🤖 Google Gemini API integration
* 📱 Responsive chatbot interface
* 😊 Emoji support
* 📎 File selection support
* ⌨️ Send messages using the Enter key
* 🔄 Loading / thinking indicator
* 🎨 Clean and modern UI
* 🧹 Clear and reset conversation functionality

🛠️ Technologies Used

* HTML5 — Structure of the chatbot
* CSS3 — Styling and responsive design
* JavaScript — Chat functionality and API requests
* Google Gemini API — AI-generated responses
* Material Symbols — UI icons

🚀 Getting Started

1. Clone the repository

git clone https://github.com/husamziadeh2005/AIchat-Bot.git

2. Open the project

cd AIchat-Bot

3. Configure the Gemini API

Open script.js and configure your Gemini API key.

const API_KEY = "YOUR_API_KEY";

⚠️ Security: Do not commit a real API key to GitHub. For a production application, the API request should be handled through a backend server or another secure mechanism.

4. Run the project

You can simply open index.html in your browser.

For the best development experience, use VS Code Live Server or another local development server.

💡 How It Works

1. The user enters a message in the chatbot.
2. JavaScript captures the message.
3. The message is sent to the Google Gemini API.
4. Gemini generates an AI response.
5. The response is displayed in the chatbot interface.
